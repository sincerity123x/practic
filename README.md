# Искра

## 1. Описание проекта

Учебный проект на Django: платформа, где авторы продают подписки, платные
посты и принимают донаты. Аналог Boosty.

Автор создаёт профиль, настраивает тарифы и публикует посты. Подписчик
оформляет подписку или отправляет донат и получает доступ к закрытому
контенту.

Стек: Python 3.12, Django 5.1, SQLite, HTML/CSS без библиотек.

- Макеты — [Figma](https://www.figma.com/design/pGimaoCT08T8LfnWg11WNz/prak?m=auto&t=CBfdXonkYgZ5bOPU-6)

## 2. Порядок установки и запуска

Нужны Python 3.11+ и Git.

```powershell
git clone <url-репозитория>
cd <папка-проекта>

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py loaddata demo
python manage.py runserver
```

Сайт — http://127.0.0.1:8000/, админка — http://127.0.0.1:8000/admin/.

Если PowerShell блокирует активацию окружения:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## 3. Аналитическая часть

**Аудитория.** Авторы, которым тесно в соцсетях: иллюстраторы, музыканты,
преподаватели. Им нужен прямой контакт с подписчиками и регулярный доход.
Вторая аудитория — подписчики, готовые платить за близкий контент.

**Доход.** Подписки на тарифы и платные посты с комиссией 10%, донаты без
комиссии. Выплаты раз в неделю от 1 000 ₽.

**Доступ.** Открытый пост видят все, закрытый — при активной подписке нужного
уровня, платный — после разовой покупки. Донат доступа не даёт.

**Метрики.** GMV, take rate, конверсия в первого подписчика, retention M1,
LTV, средний чек.

**Воронка.** Визит страницы автора → просмотр тарифов → оформление → оплата
→ продление.

**События.** `page_view`, `creator_view`, `tier_view`, `checkout_start`,
`subscription_created`, `donation_sent`, `post_unlock`, `post_view`.
